# /fund-polish — 基金申请书润色与格式终检

## 触发场景
基金申请书内容基本定稿，需要进行语言润色、说服力强化和格式合规检查。

## 工作流

### Step 1: 读取申请书全文

- 读取完整申请书内容
- 确认基金类型和目标基金的格式要求
- 如有格式模板/填写说明，一并读取

### Step 2: 语言润色（调用 `language-polisher-zh` agent）

对全文进行以下维度的润色：

#### 2.1 学术规范性
- 表述是否符合基金申请书的文体要求（不同于论文、不同于报告）
- 是否存在口语化表达、冗余表述、语病
- 被动句/主动句使用是否恰当
- 避免过度自谦或过度夸大

#### 2.2 说服力强化
- **立项依据**：是否构建了清晰的"已知→未知→本项目填补"逻辑链？
- **研究意义**：是否同时覆盖理论意义和实践价值？是否有具体场景/数据支撑？
- **创新点**：表述是否锐利、不含糊？是否避免了"一定程度上""有所创新"等弱化词？
- **研究方案**：是否给评审人"这个人真的能做出来"的信心？
- **关键句强化**：每个section的首句和末句是否有力？是否能让快速浏览的评审人抓住要点？

#### 2.3 逻辑连贯性
- 各研究内容之间的narrative thread是否清晰
- 立项依据→研究内容→技术路线→预期成果 是否一脉相承
- 段与段之间是否有合理的过渡和衔接
- 前后文是否存在矛盾之处

#### 2.4 术语一致性
- 同一概念是否全文使用同一术语（不要一会儿"深度学习"一会儿"深层学习"）
- 英文术语首次出现是否有中文对照
- 缩写是否首次出现时有全称

#### 2.5 数据准确性
- 引用的统计数据/数字前后是否一致
- 百分比、金额、年份等是否有明显错误
- 文献引用是否准确（作者、年份、期刊）

### Step 3: 格式合规检查

#### 3.1 篇幅检查
- 各章节字数是否在限制范围内（国自然正文一般不超过8000字）
- 参考文献数量是否适当
- 是否有章节过长或过短

#### 3.2 必备章节检查
根据基金类型检查必备章节是否齐全：

**国自然必备章节**：
- [ ] 立项依据与研究内容
  - [ ] 项目的立项依据（研究意义、国内外研究现状及发展趋势）
  - [ ] 项目的研究内容、研究目标、拟解决的关键科学问题
  - [ ] 拟采取的研究方案及可行性分析（技术路线、实验方案、关键技术）
  - [ ] 本项目的特色与创新之处
  - [ ] 年度研究计划及预期研究结果
- [ ] 研究基础与工作条件
  - [ ] 工作基础（与本项目相关的研究工作积累和已取得的研究工作成绩）
  - [ ] 工作条件（实验条件、数据获取途径等）
  - [ ] 申请人简历（教育经历、研究经历、代表性成果）
- [ ] 经费申请说明
- [ ] 其他需要说明的问题

#### 3.3 图表格式
- 图片分辨率是否足够
- 图表标题是否规范（图在下、表在上）
- 技术路线图是否清晰易读
- 图表编号是否连续

#### 3.4 参考文献格式
- 格式是否统一（GB/T 7714 或其他指定格式）
- 是否有遗漏的引用
- 自引比例是否合理

#### 3.5 字体/排版要求（如有）
- 是否符合基金委模板要求
- 页边距、行距、字号是否正确

### Step 4: 跨章节一致性检查

#### 4.1 研究内容 ↔ 研究方案
- 研究内容中列出的每个子课题，在研究方案中是否都有对应的方法描述
- 研究方案中的方法，是否都服务于研究内容中的目标

#### 4.2 创新点 ↔ 立项依据
- 每个创新点是否都能在立项依据中找到对应的gap/不足
- 立项依据中指出的主要gap，是否都被创新点回应

#### 4.3 经费预算 ↔ 研究方案
- 需要购买的设备/软件，在研究方案中是否有体现
- 差旅费是否与调研/合作计划匹配
- 劳务费/专家咨询费是否与团队配置匹配

#### 4.4 年度计划 ↔ 研究内容
- 年度计划是否覆盖所有研究内容
- 时间分配是否合理（不要前松后紧或前紧后松）
- 预期成果是否与研究内容对应

### Step 5: 输出润色结果与合规报告

#### 润色结果
- 逐章节展示修改（标注修改原因）
- 用户逐条确认或调整

#### 合规报告
```
## 格式合规检查报告

### 通过项 ✓
- ...

### 需修改项 ✗
- [章节/位置] 问题描述 → 建议修改方式

### 跨章节一致性
- [一致/不一致] 具体说明
```

### Step 6: 更新项目状态

- 如项目有 CLAUDE.md，更新相关状态记录

## 注意事项

- **润色不是重写**：保持申请人的原始思路和表达风格，只在规范性和说服力上提升
- **格式要求以最新版为准**：不同年份的基金申请格式可能有变化，以用户提供的模板为准
- **说服力 > 华丽**：基金申请书的核心是让评审人相信"这个问题重要、这个人能做、这个方案可行"，不是堆砌辞藻
- **关注评审人阅读体验**：评审人可能在短时间内阅读大量申请书，关键信息要一目了然
